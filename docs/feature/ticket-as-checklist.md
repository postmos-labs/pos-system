## 인입내역 등록에도 AS 체크리스트 (2026-09-08)

가맹점 360 메모의 AS 유형에만 있던 응대 원칙 체크리스트를 인입내역 등록에도 넣었다. 기술지원 인입은
사실상 AS 응대 기록인데 원칙 확인이 가맹점 메모 쪽에만 있어 두 경로의 기준이 달랐다. 항목 정의는
`src/lib/asChecklist.ts` 한 곳을 같이 쓰고, 결과는 `tickets.as_checklist`(JSONB, `supabase/143`)에
항목 id → true 꼴로 남긴다. 기술지원팀 건은 25항목을 전부 확인해야 등록된다 — 가맹점 메모와 같은
규칙이다. 컬럼이 아직 없으면 등록은 되고 "저장되지 않은 항목"으로 알린다(다른 컬럼과 같은 처리).
상세 화면에서는 접이식으로 확인 결과를 보여준다.
