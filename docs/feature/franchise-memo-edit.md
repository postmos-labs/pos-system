# 가맹접수 비고(히스토리) 수정

## 배경

- CS 직원이 가맹접수 목록의 "비고란이 수정되지 않는다"고 요청
- 목록의 비고 칸은 고정(📌)한 메모만 보여주는 표시 전용 칸이었고, 눌러도 아무 일이 없었음
- 실제 메모는 맨 오른쪽 메모 아이콘으로 여는 히스토리 서랍에서 다루는데, 추가·삭제·고정만 가능하고 이미 쓴 내용을 고치는 기능이 없었음 (고치려면 삭제 후 다시 써야 함)

## 결정

- 히스토리 서랍의 각 항목에 수정 버튼(연필) 추가
  - 마우스를 올리면 고정·삭제 버튼 옆에 나타남. 누르면 그 자리에서 입력창으로 바뀜
  - Enter 저장 / Shift+Enter 줄바꿈 / Esc 취소. 빈 내용이거나 바뀐 게 없으면 저장하지 않고 닫음
  - 작성자·작성 시각(스탬프)과 고정 상태는 그대로 두고 내용만 바꿈. 수정 이력은 따로 남기지 않음
  - 삭제와 같은 권한 기준 (별도 제한 없음)
- 목록의 비고 칸을 클릭하면 히스토리 서랍이 열림
  - 글자를 드래그해 복사하는 중에는 열지 않음
  - 키보드로는 바로 옆 메모 아이콘 버튼으로 같은 동작 가능
- 서랍에 `key={row.id}`를 걸어, 열린 채로 다른 행의 비고 칸을 눌러도 이전 행의 수정 상태가 남지 않게 함

## 참고

- 메모는 `franchise_applications.memo` 한 칸에 `[이름 YYYY. MM. DD. HH:mm] 내용` 형태로 이어 붙인 문자열이라, 수정은 해당 항목 블록의 내용 부분만 바꾸는 방식 (`updateMemoEntry`)
- 내용에 `[이름 10. 06. 10:00]` 같은 스탬프 모양 문자열을 직접 입력하면 항목이 둘로 나뉨 (새 메모 추가 때와 같은 기존 한계)
- 구형 `HistoryPanel`(FranchiseClient.tsx 내부)은 쓰이지 않는 코드라 건드리지 않음
