# 가맹점 360 관련 업무 이력 — 설치완료 탭

현장 요청(노희찬): 가맹점 화면의 관련 업무 이력에서 설치가 언제 끝났는지 알 수 없다. 설치완료 탭을 두고 완료 처리한 날짜를 찍어 달라.

## 결정 사항

- 기존 "설치 작업"·"장비 배송" 줄은 설치건 **등록일**을 보여 준다. 완료 시각은 따로 **"설치완료" 탭(category `completed`)** 에 한 줄씩 추가한다. 전체 탭에도 날짜순으로 함께 나온다.
- 시각과 처리자는 `installation_activity_logs`의 상태 변경 기록(`to_status`)에서 가져온다. DB 변경 없음.
- 설치건(설치·전환): `completed`로 바뀐 마지막 기록 → **설치 완료**
- 배송건: 대부분 택배발송에서 끝나므로 `delivery_sent`로 바뀐 마지막 기록, 없으면 `completed` 기록 → **택배 발송 완료**
- 지금 완료 상태가 아닌 건(완료 뒤 되돌린 건)은 찍지 않는다. AS는 AS 탭에서 따로 보므로 넣지 않는다.
- 상태 기록이 생기기 전에 완료된 옛 건은 기록이 없어 찍히지 않는다.
