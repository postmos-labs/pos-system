# 가맹접수 목록 — 순번(No) 열과 총 건수 강조

## 배경

- CS 직원이 "서류대기" 등 상태로 거르면 수십 건인데 행 번호가 없어 건수를 하나씩 세야 한다는 요청

## 결정

- 표 맨 앞(체크박스 다음)에 No 열 추가
  - 화면에 보이는 순서대로 1부터 번호 부여. 정렬·필터를 바꾸면 번호도 다시 매겨짐
  - 50건씩 페이지로 나뉘므로 2페이지는 51부터 이어짐 (`(page - 1) * pageSize + index + 1`)
- 총 건수는 탭 줄 맨 오른쪽의 작은 글씨에서 탭 바로 오른쪽으로 옮기고 숫자를 키움
  - 상태 필터가 걸려 있으면 "서류대기 39건"처럼 상태 이름을 앞에 붙임. 없으면 "전체 N건"

## 참고

- 총 건수는 현재 필터가 걸린 목록 전체 건수이며, 위쪽 VAN 카드·탭 숫자와는 집계 기준이 다름
- 상태 외 다른 필터(검색·VAN·날짜 등)가 같이 걸려 있어도 숫자는 그 결과 건수
- 엑셀 내보내기에는 번호를 넣지 않음
