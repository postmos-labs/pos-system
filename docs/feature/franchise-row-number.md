# 가맹접수 목록 — 순번(No) 열과 총 건수 강조

## 배경

- CS 직원이 "서류대기" 등 상태로 거르면 수십 건인데 행 번호가 없어 건수를 하나씩 세야 한다는 요청

## 결정

- 표 맨 앞(체크박스 다음)에 No 열 추가
  - 게시판식 역순 번호: 맨 위 행이 총 건수, 맨 아래 행이 1 (`filteredCount - (page - 1) * pageSize - index`)
  - 처음에는 맨 위를 1로 매겼으나, 등록일순(새 접수가 맨 위)이라 새 접수가 들어올 때마다 기존 건 번호가 전부 밀려 역순으로 바꿈. 같은 필터 기준에서는 새 접수가 와도 기존 건 번호가 유지되고, 첫 행 번호가 곧 총 건수
  - 50건씩 페이지로 나뉘므로 2페이지는 `총 건수 - 50`부터 이어서 내려감
  - 번호는 현재 필터·정렬 기준의 위치 표시이며 건을 가리키는 고유 번호가 아님. 필터를 바꾸거나 건이 필터에서 빠지면 번호가 달라짐. 고유 번호가 필요하면 DB에 접수번호 컬럼을 두는 방식을 따로 설계해야 함
- 총 건수는 탭 줄 맨 오른쪽의 작은 글씨에서 탭 바로 오른쪽으로 옮기고 숫자를 키움
  - 상태 필터가 걸려 있으면 "서류대기 39건"처럼 상태 이름을 앞에 붙임. 없으면 "전체 N건"

## 참고

- 총 건수는 현재 필터가 걸린 목록 전체 건수이며, 위쪽 VAN 카드·탭 숫자와는 집계 기준이 다름
- 상태 외 다른 필터(검색·VAN·날짜 등)가 같이 걸려 있어도 숫자는 그 결과 건수
- 엑셀 내보내기에는 번호를 넣지 않음
