# 승인함 승인 대기 목록 — 50건 초과 시 안내 문구

## 배경

- 승인함의 승인 대기 목록은 오래된 요청부터 최대 50건만 보여주는데, 잘려도 안내가 없어 "승인함에 안 보임"이 "승인할 게 없음"으로 오해됨

## 결정

- 설치완료 승인 목록 또는 이관 승인 목록이 50건 이상이면 "승인 대기 항목" 섹션 아래에 안내 문구 표시
- 조회·정렬·상한(`APPROVAL_LIST_LIMIT`)은 그대로

## 참고

- 오래된 요청부터 보이므로 새 요청은 앞 건을 처리해야 나타남
- 정확히 50건일 때도 안내가 뜸 (잘렸는지 여부를 건수만으로는 구분할 수 없어서)
