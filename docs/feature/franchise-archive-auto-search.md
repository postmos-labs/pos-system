# 가맹접수 검색 — 결과가 없으면 보관 건 자동 불러오기

## 배경

- 완료 계열 상태이면서 30일 넘게 갱신이 없는 건(보관 건)은 기본 목록에서 빠지므로, 번호·상호를 검색해도 안 나옴
- "이전 건 모두 불러오기"를 눌러야 한다는 것을 직원이 몰라 불편하다는 요청
- 성능 점검(2026-09-14)에서 만든 규칙이라 없애지는 않음

## 결정

- 통합 검색 또는 비고 검색 결과가 비면 0.6초 뒤 보관 건을 자동으로 불러와 다시 찾음
  - 한 번 불러오면 이후엔 그대로 유지 — 버튼으로 불러온 것과 같은 상태
  - 토스트로 "검색 결과가 없어 이전 건 N건까지 불러와 다시 찾았습니다" 안내
  - 평소 로딩은 변함 없음
- 불러오기가 실패하면 자동 시도는 한 번만 하고 멈춤 (같은 조건이 남아 오류 토스트가 반복되는 것을 막음). 이후엔 안내 줄의 버튼으로 받음

## 참고

- 결과가 0건일 때만 동작 — 일부라도 있으면 자동으로 읽지 않으므로, 오래된 건을 찾으려면 더 구체적으로 검색하거나 버튼 사용
- 다른 필터·탭 때문에 0건이어도 한 번 불러옴 (무해)
- 이관 승인 대기·기술지원 반려 건은 이미 보관 규칙 예외로 항상 목록에 있음
