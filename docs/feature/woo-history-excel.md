# 우국상 관리 — 선택한 가맹점 히스토리 엑셀 내보내기

## 배경

- 우국상 관리에서 가맹점의 히스토리를 보려면 가맹점을 하나씩 열어야 해서 불편함
- 체크한 가맹점의 히스토리를 엑셀로 한 번에 보고 싶다는 CS 요청

## 결정

- 가맹점을 체크하면 화면 아래에 뜨는 일괄 작업 줄에 "엑셀 내보내기" 버튼 추가. 체크하지 않으면 버튼이 나오지 않음
- 엑셀은 시트 2개
  - "가맹점 정보" — 선택한 가맹점의 화면 칸 22개 전부
  - "히스토리" — 가맹점별 비고 메모 기록을 한 줄씩. 칸은 분류·상호명·대표자명·연락처·일시·작성자·내용
- 가맹점은 화면에 보이는 순서(필터·정렬 적용), 기록은 오래된 순
  - 선택은 필터를 바꿔도 유지되므로, 지금 필터에 가려진 선택 건도 빠지지 않고 화면에 보이는 건 뒤에 붙음
- 기록이 없는 가맹점은 "(기록 없음)" 한 줄
- 파일명은 `우국상_히스토리_YYYYMMDD.xlsx`

## 참고

- 우국상의 히스토리는 비고 메모 기록뿐이며 상태 변경·통화 기록 같은 다른 이력은 이 화면에 없음
- 스탬프 없는 옛 메모는 일시가 가맹점 등록일, 작성자는 빈 칸

## 영향 파일

- `src/app/(app)/woo/wooExcel.ts` — 신규. 두 시트의 데이터를 만드는 순수 함수
- `src/app/(app)/woo/WooClient.tsx` — 버튼과 내보내기 핸들러 추가
