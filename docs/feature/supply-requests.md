# 물품요청 (2026-09-09)

직원이 필요한 소모품·비품을 올리고 실장급 이상이 승인하는 게시판. 개발요청 게시판을 본떴다.

- 항목: 물품명(필수), 수량(필수, 기본 1)과 단위, 설명·용도, 필요 시기, 긴급 여부. 요청자·팀은 로그인 정보로 채운다.
- 상태: 요청 → 승인 → 구매중 → 수령완료, 또는 반려(사유 필수). 반려된 건을 요청자가 고치면 다시 요청으로 돌아간다.
- 승인 권한: 실장·상무·대표. 설치 최종 승인과 같은 직급 판정(`canApproveFinalBy`)을 쓰고 admin·master는 항상 된다. **본인이 올린 요청도 본인이 승인할 수 있다** — 결재가 한 단계뿐이고 금액이 작아서 막으면 실장이 한 명뿐인 팀이 상무·대표까지 올라가야 한다. 목록에는 "본인 승인"으로 표시한다.
- 요청자는 승인 전(요청·반려)까지만 자기 건을 고치거나 지울 수 있다. admin·master는 어느 건이든 지운다.
- 상태가 바뀌면 요청자에게 알림이 간다(본인 처리면 안 보냄).
- 쓰기는 전부 서버 액션이 권한을 검사한 뒤 service_role로 하므로 RLS는 조회만 열어 둔다.
- 지금 넣지 않은 것: 단가·예산·결재선, 재고 실사 연동.
