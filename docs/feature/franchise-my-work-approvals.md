# 가맹접수 내 업무 탭 — 내가 승인할 차례인 이관 건 포함

## 배경

- 팀장이 "팀장 승인대기" 이관 건을 승인하려면 담당자가 다른 건이라 내 업무에 뜨지 않아, 목록에서 일일이 찾아야 한다는 요청

## 결정

- 내 업무 = 내가 담당(영업·CS)인 진행 건 + 내가 승인할 차례인 이관 건
  - 팀장은 "팀장 승인대기", CS책임은 "CS책임 승인대기" 건을 포함
  - 내가 승인요청을 올린 건은 제외 (요청자 본인은 승인할 수 없음). 요청자 계정이 삭제돼 요청자가 비어 있으면 제외하지 않음
  - 배지·승인 버튼·서버 가드와 같은 조건이라, 내 업무에 뜨면 상세에서 바로 승인할 수 있음
  - 가맹접수 상태가 완료·취소여도 승인 차례면 포함 — 승인함 목록과 같은 기준
- 내 업무 판정을 `isMyWork` 하나로 합쳐 목록 필터와 탭 건수가 같이 씀. 두 곳에 따로 두면 탭 숫자와 목록이 어긋남

## 참고

- 승인 요청 목록은 화면을 열 때 불러오므로 새 요청은 화면을 다시 열어야 반영됨 (기존 배지와 동일)
