# 가맹접수 내 업무 탭 — 내 승인 단계의 이관 대기 건 포함

## 배경

- 팀장이 "팀장 승인대기" 이관 건을 승인하려면 담당자가 다른 건이라 내 업무에 뜨지 않아, 목록에서 일일이 찾아야 한다는 요청

## 결정

- 내 업무 = 내가 담당(영업·CS)인 진행 건 + 내 승인 단계의 이관 대기 건
  - 팀장은 "팀장 승인대기", CS책임은 "CS책임 승인대기" 건을 포함
  - 내가 직접 올린 건도 포함. 팀장이 직접 올린 건이 "팀장 승인대기" 배지만 보이고 내 업무에서 빠지면 진행 상황을 따라가기 어렵다는 현장 지적 (배포 후 방콕 팟타이 펠리스 건)
  - 팀장은 본인이 올린 건에도 승인 버튼이 나옴(팀장 최종 승인 단계). CS책임 1차 승인은 요청자 본인 승인 불가 유지
  - 가맹접수 상태가 완료·취소여도 내 승인 단계의 대기 건이면 포함. 승인함은 CS책임에게만 본인이 올린 건을 뺌 (팀장에게는 본인 건도 보임)
- 내 업무 판정을 `isMyWork` 하나로 합쳐 목록 필터와 탭 건수가 같이 씀. 두 곳에 따로 두면 탭 숫자와 목록이 어긋남

## 참고

- 승인 요청 목록은 화면을 열 때 불러오므로 새 요청은 화면을 다시 열어야 반영됨 (기존 배지와 동일)
- 승인함의 승인 대기 목록은 팀장에게만 본인이 올린 건도 보이게 바뀜 (CS책임은 그대로)
- CS책임 단계에서 내가 올린 건은 승인 버튼이 없음
