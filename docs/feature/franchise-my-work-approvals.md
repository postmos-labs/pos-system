# 가맹접수 내 업무 탭 — 내 승인 단계의 이관 대기 건 포함

## 배경

- 팀장이 "팀장 승인대기" 이관 건을 승인하려면 담당자가 다른 건이라 내 업무에 뜨지 않아, 목록에서 일일이 찾아야 한다는 요청

## 결정

- 내 업무 = 내가 담당(영업·CS)인 진행 건 + 내 승인 단계의 이관 대기 건
  - 팀장은 "팀장 승인대기", CS책임은 "CS책임 승인대기" 건을 포함
  - 내가 직접 올린 건도 포함. 팀장이 직접 올린 건은 다른 팀장이 승인하므로 본인 화면에는 "팀장 승인대기"로만 보이는데, 내 업무에서 빠지면 진행 상황을 따라가기 어렵다는 현장 지적 (배포 후 방콕 팟타이 펠리스 건)
  - 승인 버튼은 본인이 올린 건에는 나오지 않음 — 요청자 본인은 승인할 수 없다는 규칙은 그대로 (버튼 조건·서버 가드는 변경 없음)
  - 가맹접수 상태가 완료·취소여도 내 승인 단계의 대기 건이면 포함. 승인함 목록과 달리 내가 올린 건도 보임
- 내 업무 판정을 `isMyWork` 하나로 합쳐 목록 필터와 탭 건수가 같이 씀. 두 곳에 따로 두면 탭 숫자와 목록이 어긋남

## 참고

- 승인 요청 목록은 화면을 열 때 불러오므로 새 요청은 화면을 다시 열어야 반영됨 (기존 배지와 동일)
- 승인함의 승인 대기 목록은 그대로
- 내 업무에 있어도 승인 버튼이 없는 건은 본인이 올린 건이거나 다른 팀장의 승인을 기다리는 건
