# 설치관리·택배발송 목록 No (설치건 고유 번호)

현장 요청(전병준): 기술지원 설치관리·택배발송 목록에 번호를 넣어 달라.

## 결정 사항

- 처음엔 화면 순서대로(위에서 1번, 페이지 넘기면 이어서) 매겼으나, 상태 칩(접수·설치완료·반려…)이나 필터를 바꿀 때마다 번호가 새로 매겨져 "몇 번 건"으로 부를 수 없다는 지적으로 바꿨다.
- 설치건마다 바뀌지 않는 번호 `installations.install_no`를 둔다(159번 마이그레이션). 기존 건은 등록 순서(created_at)대로 1부터, 새 건은 시퀀스 기본값으로 자동 부여. 어느 경로(설치관리 등록·이관·우국상)로 만들어도 DB가 매기므로 코드 변경 없음.
- 삭제된 건의 번호는 비어 있게 된다(다시 쓰지 않음).
- 검색창에 번호를 그대로 치면 그 건이 나온다.
- 마이그레이션 전에는 No 칸이 "-"로 보인다(목록은 `*`로 읽어 없는 칸은 그냥 비어 있다).
